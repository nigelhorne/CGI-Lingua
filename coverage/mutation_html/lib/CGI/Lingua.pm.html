  136: 
  137: CGI::Lingua is a powerful module for multilingual web applications
  138: offering extensive language/country detection strategies.
  139: 
  140: No longer does your website need to be in English only.
  141: CGI::Lingua provides a simple basis to determine which language to display a website.
  142: The website tells CGI::Lingua which languages it supports.
  143: Based on that list CGI::Lingua tells the application which language the user would like to use.
  144:

 2375: =head1 LIMITATIONS
 2376: 
 2377: =over 4
 2378: 
 2379: =item * B<is_rtl() covers primary-script RTL languages only>
 2380: 
 2381: C<is_rtl()> returns true for the 10 ISO 639-1 codes whose overwhelmingly
 2382: dominant script is right-to-left.  Languages with script variants (e.g.
 2383: Azerbaijani C<az>, which uses Latin in modern Azerbaijan but Arabic in Iran)
 2384: are treated as LTR.  If you serve content in multiple scripts of the same
 2385: language, inspect the sublanguage or Accept-Language header directly.
 2386: 
 2387: =item * B<plural_category() uses embedded CLDR rules, not Locale::CLDR>
 2388: 
 2389: The embedded rules cover ~70 languages and truncate fractional C<$n> to an
 2390: integer.  For full CLDR v42 accuracy (including fractional forms and
 2391: languages not in the table) install and use C<Locale::CLDR> directly.
 2392: 
 2393: =item * B<Logger must be a blessed object>
 2394: 
 2395: The C<logger> parameter is documented as accepting a code ref, array ref, or
 2396: filename, but the current implementation calls C<< $logger->$level() >> and will
 2397: die on non-blessed values.  Wrap alternative logger types in a
 2398: C<Log::Abstraction> instance before passing them to C<new()>.
 2399: 
 2400: =item * B<es-419 sublanguage returns undef>
 2401: 
 2402: Three-part regional codes such as C<es-419> (Latin American Spanish) do not
 2403: resolve to a C<sublanguage()> value because ISO 3166-1 does not define '419'.
 2404: This is a known limitation of the Locale::Object layer.
 2405: 
 2406: =item * B<Whois lookups are slow and unreliable>
 2407: 
 2408: Without C<IP::Country>, C<Geo::IP>, or C<Geo::IPfree> installed, C<country()>
 2409: falls back to Whois queries against live RIPE/ARIN/IANA servers.  These can
 2410: time out under load.  Install at least one local geo-database module and enable
 2411: the CHI cache to avoid this.
 2412: 
 2413: =item * B<Private methods are accessible from outside the package>
 2414: 
 2415: The C<_*> methods use the naming convention for privacy but Perl does not enforce
 2416: it.  C<Sub::Private> or C<Sub::Protected> should be added once all white-box
 2417: tests (C<t/function.t>, C<t/extended_tests.t>) are updated to use the public API
 2418: exclusively.
 2419: 
 2420: =item * B<IPv4-mapped IPv6 addresses are normalised to IPv4>
 2421: 
 2422: C<REMOTE_ADDR> values in the form C<::ffff:a.b.c.d> (RFC 4291 section 2.5.5)
 2423: are silently rewritten to the embedded C<a.b.c.d> IPv4 address before any
 2424: geo-lookup.  This is correct for country detection purposes but means the raw
 2425: address string is not preserved in cache keys or log messages.
 2426: 
 2427: =item * B<EU country code is irresolvable (with one exception)>
 2428: 
 2429: IP addresses that Whois reports as country C<EU> are mapped to C<'Unknown'>
 2430: unless they fall within Baidu's known subnet (RT-86809).  There is no ISO
 2431: 3166-1 country code for the European Union.
 2432: 
 2433: =item * B<country() does not cache undef results>
 2434: 
 2435: When C<country()> cannot determine a country (private IPs, loopback,
 2436: unresolvable addresses), it returns C<undef> without storing the result.  A
 2437: second call on the same object repeats the full validation pipeline.  This is
 2438: intentional: C<country()> reads C<REMOTE_ADDR> at call time rather than at
 2439: construction time, so caching C<undef> would return a wrong answer if
 2440: C<REMOTE_ADDR> changes between calls.  In practice this is rarely a problem
 2441: because C<country()> is called once per request and CGI applications typically
 2442: create a fresh object per request.
