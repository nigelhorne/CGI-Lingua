 2105: =head1 LIMITATIONS
 2106: 
 2107: =over 4
 2108: 
 2109: =item * B<is_rtl() covers primary-script RTL languages only>
 2110: 
 2111: C<is_rtl()> returns true for the 10 ISO 639-1 codes whose overwhelmingly
 2112: dominant script is right-to-left.  Languages with script variants (e.g.
 2113: Azerbaijani C<az>, which uses Latin in modern Azerbaijan but Arabic in Iran)
 2114: are treated as LTR.  If you serve content in multiple scripts of the same
 2115: language, inspect the sublanguage or Accept-Language header directly.
 2116: 
 2117: =item * B<plural_category() uses embedded CLDR rules, not Locale::CLDR>
 2118: 
 2119: The embedded rules cover ~70 languages and truncate fractional C<$n> to an
 2120: integer.  For full CLDR v42 accuracy (including fractional forms and
 2121: languages not in the table) install and use C<Locale::CLDR> directly.
 2122: 
 2123: =item * B<Logger must be a blessed object>
 2124: 
 2125: The C<logger> parameter is documented as accepting a code ref, array ref, or
 2126: filename, but the current implementation calls C<< $logger->$level() >> and will
 2127: die on non-blessed values.  Wrap alternative logger types in a
 2128: C<Log::Abstraction> instance before passing them to C<new()>.
 2129: 
 2130: =item * B<es-419 sublanguage returns undef>
 2131: 
 2132: Three-part regional codes such as C<es-419> (Latin American Spanish) do not
 2133: resolve to a C<sublanguage()> value because ISO 3166-1 does not define '419'.
 2134: This is a known limitation of the Locale::Object layer.
 2135: 
 2136: =item * B<Whois lookups are slow and unreliable>
 2137: 
 2138: Without C<IP::Country>, C<Geo::IP>, or C<Geo::IPfree> installed, C<country()>
 2139: falls back to Whois queries against live RIPE/ARIN/IANA servers.  These can
 2140: time out under load.  Install at least one local geo-database module and enable
 2141: the CHI cache to avoid this.
 2142: 
 2143: =item * B<Private methods are accessible from outside the package>
 2144: 
 2145: The C<_*> methods use the naming convention for privacy but Perl does not enforce
 2146: it.  C<Sub::Private> or C<Sub::Protected> should be added once all white-box
 2147: tests (C<t/function.t>, C<t/extended_tests.t>) are updated to use the public API
 2148: exclusively.
 2149: 
 2150: =item * B<IPv4-mapped IPv6 addresses are normalised to IPv4>
 2151: 
 2152: C<REMOTE_ADDR> values in the form C<::ffff:a.b.c.d> (RFC 4291 section 2.5.5)
 2153: are silently rewritten to the embedded C<a.b.c.d> IPv4 address before any
 2154: geo-lookup.  This is correct for country detection purposes but means the raw
 2155: address string is not preserved in cache keys or log messages.
 2156: 
 2157: =item * B<EU country code is irresolvable (with one exception)>
 2158: 
 2159: IP addresses that Whois reports as country C<EU> are mapped to C<'Unknown'>
 2160: unless they fall within Baidu's known subnet (RT-86809).  There is no ISO
 2161: 3166-1 country code for the European Union.
