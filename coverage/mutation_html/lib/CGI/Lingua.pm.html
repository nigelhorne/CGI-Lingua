   54: 
   55: No longer does your website need to be in English only.
   56: CGI::Lingua provides a simple basis to determine which language to display a website.
   57: The website tells CGI::Lingua which languages it supports.

 2132: =head1 LIMITATIONS
 2133: 
 2134: =over 4
 2135: 
 2136: =item * B<is_rtl() covers primary-script RTL languages only>
 2137: 
 2138: C<is_rtl()> returns true for the 10 ISO 639-1 codes whose overwhelmingly
 2139: dominant script is right-to-left.  Languages with script variants (e.g.
 2140: Azerbaijani C<az>, which uses Latin in modern Azerbaijan but Arabic in Iran)
 2141: are treated as LTR.  If you serve content in multiple scripts of the same
 2142: language, inspect the sublanguage or Accept-Language header directly.
 2143: 
 2144: =item * B<plural_category() uses embedded CLDR rules, not Locale::CLDR>
 2145: 
 2146: The embedded rules cover ~70 languages and truncate fractional C<$n> to an
 2147: integer.  For full CLDR v42 accuracy (including fractional forms and
 2148: languages not in the table) install and use C<Locale::CLDR> directly.
 2149: 
 2150: =item * B<Logger must be a blessed object>
 2151: 
 2152: The C<logger> parameter is documented as accepting a code ref, array ref, or
 2153: filename, but the current implementation calls C<< $logger->$level() >> and will
 2154: die on non-blessed values.  Wrap alternative logger types in a
 2155: C<Log::Abstraction> instance before passing them to C<new()>.
 2156: 
 2157: =item * B<es-419 sublanguage returns undef>
 2158: 
 2159: Three-part regional codes such as C<es-419> (Latin American Spanish) do not
 2160: resolve to a C<sublanguage()> value because ISO 3166-1 does not define '419'.
 2161: This is a known limitation of the Locale::Object layer.
 2162: 
 2163: =item * B<Whois lookups are slow and unreliable>
 2164: 
 2165: Without C<IP::Country>, C<Geo::IP>, or C<Geo::IPfree> installed, C<country()>
 2166: falls back to Whois queries against live RIPE/ARIN/IANA servers.  These can
 2167: time out under load.  Install at least one local geo-database module and enable
 2168: the CHI cache to avoid this.
 2169: 
 2170: =item * B<Private methods are accessible from outside the package>
 2171: 
 2172: The C<_*> methods use the naming convention for privacy but Perl does not enforce
 2173: it.  C<Sub::Private> or C<Sub::Protected> should be added once all white-box
 2174: tests (C<t/function.t>, C<t/extended_tests.t>) are updated to use the public API
 2175: exclusively.
 2176: 
 2177: =item * B<IPv4-mapped IPv6 addresses are normalised to IPv4>
 2178: 
 2179: C<REMOTE_ADDR> values in the form C<::ffff:a.b.c.d> (RFC 4291 section 2.5.5)
 2180: are silently rewritten to the embedded C<a.b.c.d> IPv4 address before any
 2181: geo-lookup.  This is correct for country detection purposes but means the raw
 2182: address string is not preserved in cache keys or log messages.
 2183: 
 2184: =item * B<EU country code is irresolvable (with one exception)>
 2185: 
 2186: IP addresses that Whois reports as country C<EU> are mapped to C<'Unknown'>
 2187: unless they fall within Baidu's known subnet (RT-86809).  There is no ISO
 2188: 3166-1 country code for the European Union.
 2189:
